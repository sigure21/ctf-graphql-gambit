# GraphQL Gambit

**Category:** Web / Code Injection  
**Difficulty:** DreamHack Silver 후반 ~ Gold 초입  
**Points:** 400

공개 CI task explorer는 익명 사용자에게 빌드 큐 검색 기능을 제공합니다. GraphQL introspection은 꺼져 있고 운영 credential은 응답에 포함되지 않는다고 합니다.

필터 처리 경계를 분석해 web-server process에 보관된 flag를 회수하세요.

```text
URL: http://<challenge-host>:<port>
Flag format: flag{...}
```

인증 우회, 비밀번호 무차별 대입, 서비스 거부 공격은 필요하지 않습니다. 실제 인터넷 서비스에 같은 payload를 전송하지 마십시오.
